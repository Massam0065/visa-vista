VISA VISTA – SUCCESS STORIES DEMO

1. Extract this ZIP.
2. Open the extracted visa_vista_restore folder in VS Code.
3. Start index.html with the Live Server extension.
4. Open success-stories.html to view the separate Success Stories page.
5. Open /admin.html to manage stories.
6. Demo password: VistaDemo123

All story fields are optional. You can publish a photo only, text only, or any combination.
Photos should be under 1.2 MB in this browser demo.

IMPORTANT: This is a local browser demo. Stories are saved only in the same browser using localStorage. They are not shared with other devices or public visitors on a deployed website. A server backend and database are required for live publishing. Get client permission before publishing their photo or personal story.

Video support: Admin accepts optional MP4 or WebM videos up to 2 MB for this browser-only demo. Uploaded videos appear with playback controls on the separate Success Stories page. Browser storage is limited; large or many media files may fill it. This is not a production hosting solution.
