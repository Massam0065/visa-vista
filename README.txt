VISA VISTA WEBSITE - STARTER PROJECT

HOW TO OPEN
1. Extract visa_vista_website.zip.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. In VS Code, install the "Live Server" extension if you do not have it.
5. Right-click index.html and choose "Open with Live Server".
